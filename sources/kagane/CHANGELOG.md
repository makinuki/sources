# Changelog

All notable changes to the kagane source plugin are recorded here. The plugin
version follows semver; contract-level changes follow the ABI versioning policy
defined in the spec repository (SPECIFICATION.md, Section 7).

## [1.0.1] - 2026-09-12

- Raise the PDK floor to the release that handles the absent value a host
  returns for a void storage import, which is what failed during the integrity
  handshake.

## [1.0.0] - 2026-09-12

- Add the Kagane source plugin: search, details, chapter list and page images.
